# 📱 Social Media Images - To Create Later

## 🎯 What You Need

Two images that appear when people share your website on social media.

### **1. og-image.png**
- **Size:** 1200 x 630 pixels
- **Format:** PNG
- **Location:** `images/og-image.png`
- **Used by:** Facebook, LinkedIn, WhatsApp, Slack, iMessage

### **2. twitter-card.png**
- **Size:** 1200 x 675 pixels (or reuse 1200x630)
- **Format:** PNG
- **Location:** `images/twitter-card.png`
- **Used by:** Twitter/X

---

## 🎨 Design Specs

### **What to Include:**
1. ✅ Medisight logo (prominent)
2. ✅ Main tagline: "Personal Precision, Powered by AI"
3. ✅ Key stat: "96.8% Precision Rate"
4. ✅ Secondary stat: "15,000+ Medical Studies" or "Trusted by Google"
5. ✅ Your brand gradient background (#0EA5E9 → #6366F1)
6. ✅ Domain: "medisight.ai" (small text, bottom right)

### **Design Guidelines:**
- **Background:** Use your blue-to-purple gradient
- **Fonts:** Inter (same as website)
- **Logo:** Top-left or centered
- **Text:** High contrast, readable at small sizes
- **Clean:** Don't overcrowd, leave white space
- **Professional:** Enterprise-grade look

---

## 🛠️ How to Create

### **Option 1: Canva (Recommended)**
1. Go to https://canva.com
2. Create custom size: 1200 x 630 px
3. Add gradient background
4. Upload Medisight logo from `images/logo/Medisight_Logo_Gradient.png`
5. Add text elements with stats
6. Export as PNG
7. Save as `og-image.png`
8. For Twitter: resize to 1200 x 675 or reuse same image

### **Option 2: Figma**
1. Create 1200 x 630 frame
2. Add gradient fill (#0EA5E9 to #6366F1 at 135°)
3. Place logo and text
4. Export as PNG @2x

### **Option 3: Hire Designer**
- Fiverr: $10-30
- Upwork: $25-50
- Search: "social media preview card design"

**Provide designer with:**
- This document
- Your logo file
- Brand colors: #0EA5E9, #3B82F6, #6366F1
- Font: Inter (Google Font)
